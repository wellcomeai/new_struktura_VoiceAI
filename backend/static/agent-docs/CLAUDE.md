# Voicyfy Agent Docs — публичная документация `/static/agent-docs/`

Руководство пользователя по продукту **Voicyfy Agent** (автономный агент для
звонков, приложение — `/static/agent.html`, его код — `backend/static/agent/`).

- **Прод-URL:** `https://voicyfy.ru/static/agent-docs/` — `index.html` отдаётся
  автоматически, т.к. в `app.py` статика смонтирована с `StaticFiles(..., html=True)`.
  Отдельного backend-роута нет; страница публичная, без авторизации и без API-запросов.
- **Откуда ведут ссылки:** навбар и футер лендинга (`frontend/src/components/
  Navbar.jsx`, `Footer.jsx`), кнопка «?» в приложении агента (`agent.html`),
  редирект со старого адреса `/static/agent-guide.html`.

## Карта файлов

| Файл | Назначение |
|------|-----------|
| `index.html` | Вся разметка: топбар, сайдбар-оглавление, 15 секций-глав (`section.chapter` с `id`), демо-мокапы, футер |
| `docs.css` | Все стили. Оболочка — палитра лендинга (#2563eb, Inter+Syne). Компонентные мокапы (`ob-*`, `.flow/.phase`, `.chat-demo`, `.tg-phone`, `.status-badge`) перенесены из `agent/agent.css` и старого `agent-guide.html` |
| `docs.js` | Мобильное меню, scrollspy, автогенерация «← / →» между главами, переключатель «До/Во время/После» (глава Архитектура), карусель-тур (`TOUR_CALL`) |

## Как добавить главу

1. В `index.html` добавь `<section class="chapter" id="<id>">` (eyebrow «Раздел N»,
   `h2`, контент, callout «Что нужно запомнить»).
2. Добавь ссылку `<a class="sb-link" href="#<id>">` в сайдбар в нужную группу.
   Порядок ссылок сайдбара определяет и scrollspy, и навигацию «пред./след.» —
   больше ничего править не нужно.

## Как добавить слайдовый тур

1. В `docs.js` опиши массив слайдов `{badge, title, text, art}` (`art` — HTML-мокап,
   используй классы `ob-mock`, `ob-row`, `ob-talk`, `ob-bubble`, `ob-funnel`).
2. Зарегистрируй его в объекте `TOURS` под ключом `<name>`.
3. В `index.html` вставь `<div class="demo tour" data-tour="<name>"></div>`.

## Синхронизация с продуктом

Содержимое должно соответствовать реальному приложению агента:
- 5 документов агента и их вкладки — `agent.html` (`doc_who_am_i` и др.);
- стадии воронки — `STAGE_META` в `agent/core.js` (Новый/В работе/Успех/Отказ/Не звонить);
- набор карточек главного экрана (мокап в главе 3) — раскладка `agent.html`.
Меняется продукт — обнови соответствующую главу.
