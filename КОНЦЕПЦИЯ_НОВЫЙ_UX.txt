1. СУТЬ ПЕРЕХОДА
--------------------------------------------------------------------------------

Сегодня платформа устроена «по провайдерам»: у каждой голосовой технологии
(OpenAI, Gemini, Cartesia, Яндекс, Каскад, Fish...) — своя страница, свой
интерфейс создания ассистента, и каждый клиент обязан принести собственные
API-ключи всех провайдеров. Это сложно для пользователя и не приносит нам
выручки с использования.

Мы переходим к модели «по задаче»:

  * ОДНА страница «Голосовые ассистенты» вместо семи страниц провайдеров.
    Голосовая модель — это просто настройка ассистента, а не отдельный раздел.

  * НАШИ ключи вместо клиентских. Все обращения к AI-провайдерам идут через
    серверные ключи Voicyfy. Клиенту больше не нужно регистрироваться у
    OpenAI, Google, Fish и т.д. — он просто выбирает модель и работает.

  * ЕДИНАЯ ВАЛЮТА — рублёвый кошелёк на аккаунт. Каждая модель имеет
    понятную цену «X рублей за минуту разговора». Клиент пополняет один
    баланс и пользуется любыми моделями.

3. СТРАНИЦА «ГОЛОСОВЫЕ АССИСТЕНТЫ»
--------------------------------------------------------------------------------

Создание и редактирование ассистента собирается на одном экране:

  * Общие поля для всех моделей: имя ассистента, первая фраза (приветствие),
    системный промпт.

  * Выбор голосовой модели. При выборе или смене модели прямо на странице
    перерисовывается блок её голосовых настроек: список голосов у
    OpenAI/Gemini/Яндекса/Каскада, Voice ID у Cartesia и Fish и т.д.
    Рядом с каждой моделью отображается её цена: «X ₽/мин».

  * Функции — единый таб, одинаковый для всех моделей. Набор функций
    (Google-таблицы, календарь, вебхуки, SMS, CRM и прочее) не зависит от
    выбранной модели; при смене модели меняются только голосовые настройки.

  * База знаний — таб внутри ассистента.

  * Тестирование и код встраивания — как и раньше, табы страницы.

Отдельное осознанное решение: у Gemini не выводим выбор подмодели и режим
«размышлений» (thinking) — они скрыты намеренно ради скорости ответа
ассистента. Это фича, а не ограничение.


4. ЛИНЕЙКА МОДЕЛЕЙ И ЦЕНЫ
--------------------------------------------------------------------------------

Формула ценообразования: себестоимость минуты разговора -> перевод в рубли
по курсу 90 ₽/$ -> плюс 25% маржи -> округление вверх до рубля.

Витрина (цена минуты, списывается с кошелька Voicyfy):

  ┌────────────┬──────────────────────┬─────────────┬────────────────────────┐
  │ Модель     │ Себестоимость ₽/мин  │ Цена ₽/мин  │ Примечание             │
  ├────────────┼──────────────────────┼─────────────┼────────────────────────┤
  │ Каскад     │ ~0,2 (только LLM)    │ 0 (промо)   │ топовый русский звук;  │
  │            │                      │             │ ASR/TTS/связь платит   │
  │            │                      │             │ баланс телефонии       │
  │ Gemini     │ ~1,4                 │ 2           │ эконом-флагман         │
  │ Fish       │ ~2,3–2,8             │ 3           │ переходим на платную   │
  │            │                      │             │ TTS-модель s2.1-pro    │
  │ Яндекс     │ ~3,0                 │ 4           │ только модель 260528;  │
  │            │                      │             │ цены в рублях, без     │
  │            │                      │             │ курсового риска        │
  │ Cartesia   │ ~4,1                 │ 6, потом 4  │ после перевода мозга   │
  │            │                      │             │ на realtime-mini       │
  │ OpenAI     │ ~5,7                 │ 8           │ премиум                │
  └────────────┴──────────────────────┴─────────────┴────────────────────────┘

Каскад делаем бесплатным осознанно: он существует только в телефонии, где
каждая минута и так стоит клиенту денег на балансе телефонии, поэтому
злоупотребление невыгодно самому клиенту, а наш расход ограничен копейками
за текстовый LLM. Это маркетинговый крючок: «бесплатный голосовой ассистент
с лучшим русским звучанием — платите только за связь».

Цены не зашиваются в код, а хранятся в редактируемой таблице тарифов:
изменение цены (включая ноль каскада) — правка из админки без релиза.

Следующий шаг оптимизации: мозг Cartesia-ассистентов переводится с полной
realtime-модели на mini-версию — себестоимость падает почти вдвое, витрина
снижается с 6 до 4 ₽/мин.


5. ЕДИНЫЙ КОШЕЛЁК И МЕХАНИКА СПИСАНИЯ
--------------------------------------------------------------------------------

Кошелёк:

  * Один рублёвый баланс на аккаунт (хранение в копейках).
  * Пополнение через Робокассу — та же платёжная механика, что уже работает
    для подписок, добавляется тип платежа «пополнение кошелька».
  * Каждая операция (пополнение, списание, возврат, коррекция) фиксируется
    в журнале транзакций; вместе со списанием сохраняются фактические
    секунды и токены сессии — так мы видим реальную маржу каждой модели
    и корректируем цены по фактам, а не на глазок.
  * Кредиты оркестратора (LLM «второго мозга» агента) — отдельный продукт,
    он в этой реформе не участвует. Отдельный кошелёк каскад-кредитов
    упраздняется — каскад становится бесплатным.
  * Новому аккаунту — приветственный грант (размер обсуждается,
    ориентир 50–100 ₽).

Списание в веб-виджете (сессия идёт через наш сервер, полный контроль):

  1. Старт сессии: проверка баланса (минимум — цена одной минуты).
  2. Во время разговора: посекундный счётчик, промежуточное списание
     раз в 60 секунд. Баланс дошёл до нуля — ассистент корректно
     завершает разговор.
  3. Конец: досписание за фактический хвост. Минимальная тарификация
     10 секунд. В минус не уходим.

Списание в телефонии (звонок идёт внутри Voximplant):

  1. Старт звонка: сценарий запрашивает у нас конфигурацию — это шлагбаум.
     Баланс ниже порога (три цены минуты) — ключ не выдаётся, звонок
     не стартует.
  2. Защита от сверхдлинных звонков: жёсткий лимит длительности звонка
     (30 минут) на первом этапе; следующей итерацией — ежеминутный
     «пульс» из сценария с промежуточным списанием и командой завершить
     звонок при нулевом балансе.
  3. Конец звонка: сценарий передаёт отчёт (длительность, токены) —
     финальное списание по фактическим секундам. Не хватило — списание
     в ноль с пометкой, в минус не уходим.


6. ТЕЛЕФОНИЯ: РАЗДЕЛЕНИЕ ДВУХ БАЛАНСОВ
--------------------------------------------------------------------------------

У клиента два независимых баланса, и это честно проговаривается в интерфейсе:

  * Кошелёк Voicyfy — оплачивает «мозг и голос» ассистента (цена модели
    за минуту).
  * Баланс телефонии (дочерний аккаунт Voximplant, клиент пополняет его
    напрямую, как и сейчас) — оплачивает минуты связи, телефонные номера,
    а для Каскада также распознавание и синтез речи.

Никаких надбавок «за телефонию» в цене модели нет. Под выбором модели
выводится пояснение: «Минуты связи при звонках оплачиваются с баланса
телефонии».


7. ПЕРЕХОД НА СЕРВЕРНЫЕ КЛЮЧИ
--------------------------------------------------------------------------------

Механика остаётся прежней: сценарии и виджеты, как и сейчас, получают
конфигурацию (ключ, промпт, голос, функции) от нашего бэкенда в момент
старта разговора. Меняется только источник ключа: вместо ключа из профиля
пользователя бэкенд подставляет серверный ключ из окружения (env).

Принципиально: ключи НЕ копируются в базу данных в поля пользователей —
подмена происходит в точке выдачи конфигурации. Это даёт:

  * мгновенную ротацию ключей одной правкой окружения;
  * отсутствие утечек секретов через профили и экспорт;
  * естественную точку контроля баланса: нет денег — ключ не выдан —
    разговор не начался (каскад уже работает по этой схеме).

Серверные ключи заводятся для: OpenAI (уже есть), Gemini, Fish, Cartesia,
Яндекс. Поля пользовательских ключей скрываются из интерфейса настроек.
На переходный период допустим мягкий режим: у кого свой ключ прописан —
работает бесплатно по-старому; нет ключа — наш ключ и списание с кошелька.
Это же — ответ на миграцию существующих клиентов: ничего не ломается.

Важные изменения в моделях при переходе:
  * Fish: синтез переводится с бесплатной модели s2.1-pro-free на платную
    s2.1-pro (free-уровень без гарантий и может закрыться).
  * Яндекс: оставляем только модель speech-realtime-260528 (втрое дешевле
    альтернативы при том же качестве сценариев).

  * Таблицы ассистентов в базе данных — остаются как есть.

  * Дочерние аккаунты Voximplant и их пополнение — как сейчас.
  * Механизм функций — уже единый для всех моделей.
  * Подписочные тарифы (лимит ассистентов, доступ к CRM/телефонии) —
    сохраняются, кошелёк дополняет их, а не заменяет.

Из изменений в базе данных на весь план — только два аддитивных дополнения:
колонка рублёвого баланса у пользователя и маленькая таблица тарифов.
