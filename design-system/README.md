# Дизайн-система VoksiAI — пакет для переноса

Это полный перенос дизайн-системы и UI платформы Voicyfy (voicyfy.ru) для копии продукта
под брендом **VoksiAI** для рынка Кыргызстана. Пакет самодостаточен: спеки в Markdown +
готовые CSS/JS/иконки, которые подключаются как есть. Читать по порядку.

## Как это устроено в одном абзаце

Кабинет — vanilla HTML/CSS/JS без фреймворков и сборки, отдаётся FastAPI как статика. Один
файл токенов и компонентов (`voksiai.css`), один файл поведения (`ui.js`), один файл меню
(`sidebar.js`). Каждая страница: `<body class="vf">` → сайдбар 256px (меню рисует скрипт) →
топбар 64px → контент. Иконки — SVG-спрайт Lucide, логотипы моделей — отдельные SVG. Шрифты
Inter (текст) и Syne (латинский wordmark, цифры). Лендинг — отдельное React-приложение, которое
подключает тот же `voksiai.css` и добавляет `landing.css`; дисплейный шрифт там Unbounded.
Никаких UI-библиотек для карточек, модалок, табов и селектов — всё своё, описано в `02`.

## Порядок работы для исполнителя (другой Claude Code)

1. Скопировать `css/`, `js/`, `icons/` в `static/` проекта VoksiAI по путям
   `/static/css/`, `/static/js/`, `/static/icons/`. Пути внутри файлов абсолютные
   (`/static/icons/ui.svg`, `/static/icons/models/…`) — если структура другая, заменить.
2. Заменить бренд-ассеты: логотип, favicon-набор, `og-image.png`, `manifest.json`
   (`theme_color: #2a5ce8`). Список в `01-foundations.md` §4.4.
3. Собрать каркас страницы по `03-layouts.md` (каркас A) и шаблону `<head>` из
   `01-foundations.md` §5. Проверить, что сайдбар, кошелёк и топбар выглядят как в спеке.
4. Реализовать страницы по `04` и `06`, лендинг по `05`. Классы и размеры брать из спек и
   готового CSS, не придумывать новые токены.
5. Подключить словарь `i18n/ru.json` по `07-i18n.md`, добавить `ky.json`, переключатель языка.
6. Пройтись по таблицам «Что менять для VoksiAI» в начале `04`, `05`, `06`: валюта сом,
   часовой пояс Бишкек, телефоны `+996`, юридические тексты, платёжный шлюз, домен, демо-ассистент.

## Что намеренно не перенесено

- Бэкенд, API и схема БД: страницы дёргают те же эндпоинты, что в Voicyfy (перечислены в
  спеках как `/api/...`); их реализация — за пределами дизайн-системы.
- Полные тексты девяти статей-гидов дашборда (в `04` только заголовки и карточки).
- Голосовые виджеты (`widget.js`, `gemini-widget.js`) и Chrome-расширение.
- Легаси-страницы по провайдерам (`agents.html`, `gemini-agents.html`, …) — в Voicyfy они
  редиректятся на единую страницу ассистентов и не нужны в новом продукте.
- Старый лендинг `index.html` (vanilla) — не обслуживается на корне.
