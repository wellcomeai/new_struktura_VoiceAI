# Гайд «OpenSaaS на Amvera — Часть 1: запуск за 30 минут»

Исходники PDF-инструкции по развёртыванию шаблона OpenSaaS на хостинге Amvera.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Исходник гайда — весь текст и вёрстка здесь |
| `assets/img/figNN.png` | Скриншоты (нумерация совпадает с «Рис. N» в тексте) |
| `assets/fonts/` | Inter и JetBrains Mono, встраиваются в PDF |
| `build.py` | Сборка PDF из `index.html` |
| `OpenSaaS-Amvera-Chast-1.pdf` | Готовый документ, 27 страниц |

## Пересборка

```bash
pip install playwright pypdf
python3 docs/opensaas-guide/build.py
```

Браузер Chromium должен быть установлен в системе — путь к нему ищется
в `CHROME_CANDIDATES` внутри `build.py`.

Документ рендерится дважды: без колонтитула и с ним. В итоговый файл берётся
обложка из первого прогона и остальные страницы из второго — так номер
страницы не попадает на титул.

## Правки

Текст и структура правятся прямо в `index.html`. Готовые компоненты:

- `<div class="box">` — синяя врезка (пояснение), модификаторы `warn`, `danger`, `tip`
- `<div class="code">` — тёмный блок кода, `code light` — светлый
- `<figure>` — иллюстрация с подписью; классы `wide`, `tall`, `sm` управляют высотой
- `<section class="step">` — шаг с номером, начинается с новой страницы
- `<div class="grid2">`, `<div class="flow">` — сетка карточек и схема процесса

## Скриншоты

Учётные данные на скриншотах закрыты плашками «скрыто»: пароль базы (`fig04`),
токены GitHub (`fig08`, `fig09`, `fig10`) и строка подключения (`fig12`).
При замене скриншотов проверяйте, что в кадр не попали пароли и токены.
