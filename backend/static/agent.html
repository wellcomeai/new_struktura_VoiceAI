Правила и цели
Ассистент
Смена типа создаст нового голосового ассистента. Нужны соответствующие API-ключи. Cascade работает на нашем ключе и списывает кредиты каскада.
Настройки агента
Оркестратор · текстовый чат-агент
Мозг-планировщик: ведёт CRM, планирует звонки, готовит стратегию каждого звонка и анализирует результат. В живом телефонном разговоре эти инструкции НЕ используются.
Правила планирования и работы с контактами, которые не вписываются в документы компании.
Оркестратор сможет отправлять события (заявки, лиды, результаты звонков) в n8n / Make / Zapier или любой HTTP endpoint через функцию send_webhook. Оставьте пустым, чтобы отключить.
Голосовой агент · живой звонок
Как агент ведёт себя в телефонном разговоре с клиентом: голос, тон, что говорить и чего избегать.
С чего агент начинает разговор, когда звонят ему. Подставьте {name} — вместо неё подставится имя из карточки контакта, если звонящий есть в базе агента (для незнакомых номеров переменная просто убирается). Оставьте пустым — будет использовано приветствие по умолчанию.
Правила поведения именно в живом разговоре. Добавляются к промпту голосового агента.
Публичный API · приём заявок извне
Шлите заявки с формы сайта или из вашей CRM по секретному ключу — агент сам решит, что с ними делать (создаст контакт, поставит звонок, ответит). Запросы — только со своего сервера (server-to-server).

Импорт контактов
Формат файла (.xlsx или .csv):
Колонки: Имя, Телефон*, Компания, Должность, Информация о клиенте, Задача, Описание задачи, Когда звонить. Обязателен только телефон. Если колонки «Когда звонить» нет — звонки распределятся автоматически (старт через час, параллельно по 5).
Время указывается по МСК (Москва, UTC+3)
Лимит: до 1000 контактов за один импорт.
Для импорта на балансе должны быть кредиты оркестратора — ими оплачивается работа AI-оркестратора по каждому контакту: подготовка стратегии перед звонком и анализ результата после (≈30 кредитов на контакт). Точная стоимость будет показана на шаге предпросмотра.
